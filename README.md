# Dicoding JavaScript submissions

Submissions for the Dicoding JavaScript fundamentals class, one topic per folder.

| Folder | Topic |
|---|---|
| `01-writing-comments` | Writing meaningful comments |
| `02-code-style` | Code style conventions |
| `03-writing-test` | Basic unit testing |
| `optional-04-oop` | Object-oriented programming |
| `optional-05-recursive` | Recursive functions |
| `optional-06-full-coverage-testing` | Testing up to full code coverage |
| `optional-07-real-world-scenario` | Real-world scenario |

Each folder holds `instruksi.md` (the assignment) and `index.js` (the answer). Folders with tests also ship their own `index.test.js` and `package.json`:

```bash
cd 03-writing-test
npm install
npm test
```
